# Wheel of Creativity scaffolding

Clickable review build of Katherine Robertson-Pilling's Wheel of Creativity app. Placeholder copy. No payments, no email storage, no backend.

## Install as an app
Host this folder on HTTPS (GitHub Pages works). Open the site in a phone browser, then use Add to Home Screen. The manifest and service worker make it a PWA.

## Files
- `index.html` — the app
- `manifest.webmanifest` — install name, icon, standalone display
- `sw.js` — offline cache
- `icons/` — home-screen icons
- `NOTES.md` — assumptions and open questions
